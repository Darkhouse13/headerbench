# Contributing

Issues are welcome: bug reports, ModHeader exports that fail to import, rules that behave differently from what the editor says.

Pull requests may not be accepted. The project is source available, not open source, and is maintained by one person who needs to keep full ownership of the code. If you want to propose a change, open an issue first.

When you file a bug, paste the text from Settings > Support > Copy diagnostics (it contains no header values, variables or licence key).
